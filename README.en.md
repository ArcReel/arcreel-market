# ArcReel Official Market Source

[中文](README.md)

This is the official **market source** for [ArcReel](https://github.com/ArcReel/ArcReel): a GitHub repository of installable entries. The only entry type today is the **endpoint**, a custom endpoint definition file. ArcReel ships with this source preconfigured, so you can browse and install entries from the **Market** section of the settings page.

This repository is also a GitHub template: fork it or click **Use this template** and you get a valid third-party market source.

This repository does not contain the endpoint definitions built into ArcReel. Built-in endpoint keys and market entry slugs are separate namespaces.

## Browse and install

1. Open **Market** in ArcReel settings. The official source is preconfigured and enabled.
2. Pick an entry and read the install confirmation first: the raw `auth` section, the `submit.url` / `poll.url` your credentials are sent to, and the `hints`. Install only when they look right.
3. The installed endpoint appears in the **Endpoints** list and can be edited in place. When upstream publishes a new version, it shows **Update available**.

Market definitions only describe how to call an API. They carry no credentials. You enter your API key when creating a provider, and it stays in your own ArcReel instance.

## Layout

```text
arcreel-market.json              # index, generated by CI from endpoints/; do not edit by hand
endpoints/
  <slug>/
    definition.json              # definition file; entry metadata lives only in its meta
    icon.png                     # optional: PNG / WebP / SVG, square, at most 64 KB
```

- The directory name is the slug. It must match `^[a-z0-9][a-z0-9-]{0,63}$` and be unique within the source.
- Index entries are a projection of the definition `meta`: `name`, `author`, `version`, `description`, `homepage` and `min_app_version` are all read from `meta`.
- `meta.min_app_version` is optional: the lowest ArcReel version this definition needs.

Example `endpoints/<slug>/definition.json`:

```json
{
  "kind": "declarative",
  "schema_version": "1.1.0",
  "meta": {
    "name": "Example Video Gateway",
    "author": "your-github-name",
    "version": "1.0.0",
    "description": "Example definition for an OpenAI-style video generation gateway.",
    "homepage": "https://github.com/your-github-name/example-video-gateway",
    "hints": {
      "base_url": "https://api.example.com",
      "suggested_models": [{ "id": "example-video-1" }]
    }
  },
  "auth": { "headers": { "Authorization": "Bearer {{ api_key }}" } },
  "submit": {
    "method": "POST",
    "url": "{{ base_url }}/v1/videos",
    "body": { "model": "{{ model }}", "prompt": "{{ prompt }}", "duration": "{{ duration }}" },
    "extract": { "task_id": ["$.id"], "error": ["$.error.message"] }
  },
  "poll": {
    "method": "GET",
    "url": "{{ base_url }}/v1/videos/{{ task_id }}",
    "extract": { "status": ["$.status"], "video_url": ["$.video_url"], "error": ["$.error.message"] }
  }
}
```

You don't need to write this by hand: tune the definition under **Endpoints** in ArcReel, click **Export**, and save the file as `endpoints/<slug>/definition.json`.

## Run your own market source

1. Fork this repository, or click **Use this template** to create a new one.
2. Enable workflows under **Settings → Actions** in the new repository (forks don't run workflows by default).
3. Add or remove `endpoints/<slug>/` and push to the default branch. `github-actions[bot]` regenerates and commits `arcreel-market.json`. If your default branch isn't `main`, change the branch name in `.github/workflows/publish-index.yml`.
4. In ArcReel, open **Market → Manage sources**, add a source and enter `owner/repo`.

Each workflow is a single `uses:` line. Validation and generation rules are maintained in the ArcReel repository and follow its updates, so there is nothing for you to maintain.

### Without CI

You can disable Actions and write `arcreel-market.json` at the repository root yourself. An empty index looks like this:

```json
{
  "schema_version": "1.0.0",
  "name": "my-market",
  "entries": []
}
```

Each entry needs `type` (always `endpoint`), `slug`, `path` (such as `endpoints/<slug>/definition.json`), `media_type` (always `video`), plus `name`, `author`, `version` and the other fields matching the definition `meta`; add `icon` if there is one. ArcReel refuses to install an entry whose fields don't match its `meta`.

GitHub is optional too: any `https://` URL ending in `arcreel-market.json` works as a source address, and entry paths resolve relative to the index's directory.

### Advanced

From an ArcReel source checkout, run `uv run python -m lib.market check <market-source-dir>` to run every CI check locally; `generate <market-source-dir>` regenerates the index locally.
